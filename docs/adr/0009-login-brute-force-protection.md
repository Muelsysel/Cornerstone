# ADR-0009: 登录防爆破——网关 IP 限流 + 账号级锁定

Status: accepted

登录接口（`POST /auth/login`）暴露于公网，面临账号密码暴力破解与定向爆破风险。v3 落地**双层防护**：

1. **网关 IP 限流（请求层）**：`/auth/login` 路由使用独立更严的 `RedisRateLimiter`（每秒 5 令牌、桶 10），其余路由用默认限流器（10/20）；按客户端 IP 限流（`ipKeyResolver`），超出返回 HTTP 429（前端有友好提示）。
2. **账号级锁定（应用层）**：`LoginService` 用 Redis 键 `login:fail:{username}` 计数连续失败（`INCR` + 首次失败设 5 分钟 TTL）；连续失败 ≥5 次锁定该账号 5 分钟（即使密码正确也拒绝，返回业务 401 与锁定消息）；登录成功清除计数。

**降级策略**：Redis 不可用时计数/查询降级——不阻塞登录（可用性优先于防爆破）；失败计数失败不影响"密码错误"正常拒绝。**审计完整性**：锁定拒绝同样投递登录日志（status=1，消息"登录失败次数过多，已锁定"），不静默丢弃。

Consequences: 爆破被有效缓解（IP 层限速 + 账号层锁窗）；锁定窗口内合法用户登录受阻 5 分钟（可接受，v4 候选：指数退避或验证码）；计数键 5 分钟 TTL 自动过期，无手动清理负担；网关限流经 Redis 共享，多实例网关计数一致。

Considered Options: 单靠网关 IP 限流（拒绝：攻击者可换 IP 继续爆破，无法保护被猜中的弱密码账号）；单靠账号锁定（拒绝：无 IP 层缓解，分布式爆破放大请求）；验证码/滑块（用户体验负担重，列为 v4 候选）。
