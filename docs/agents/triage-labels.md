# Triage Labels

技能（skills）以五个规范化的分类角色表述问题状态。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| 角色（角色名） | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求完整，可交给 AFK agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不处理 |

技能提到某个角色（如"打上 AFK-ready 分类标签"）时，用上表对应的标签字符串。

如需调整，只改右列即可，保持角色语义不变。
