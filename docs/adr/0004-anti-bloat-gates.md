# ADR-0004: 反臃肿机制——扩展的五道门槛

Status: accepted

为防止项目随版本膨胀腐化，任何扩展必须过五道门槛：**API 契约先行**（跨服务调用只能经 `cornerstone-api` 定义，禁止直连/复制 DTO）；**模块边界记录**（每模块 CONTEXT.md 记录职责/边界/不做的事，扩展必须重写边界）；**ADR 门槛**（新模块、新功能、依赖升级必须过 ADR）；**依赖集中管理**（版本只在父 POM BOM 定义，模块禁止私自引版本）；**活模板**（新模块照 `cornerstone-demo` 克隆）。

Consequences: 扩展成本显性化（写文档、过 ADR），换来的是一致性与可维护性——这正是脚手架对下载者的价值承诺。
